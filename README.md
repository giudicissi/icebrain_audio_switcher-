IceBrain Audio Switcher

Gerenciador de áudio desenvolvido para facilitar a troca rápida entre dispositivos de áudio.

O projeto foi criado com foco em praticidade para usuários de realidade virtual (VR), especialmente durante o uso de simuladores, permitindo alternar entre diferentes dispositivos de áudio de forma simples e eficiente, sem a necessidade de acessar configurações do sistema operacional.

IceBrain Audio Switcher

Audio management utility designed to simplify and speed up switching between audio output devices.

The project was created with a focus on convenience for Virtual Reality (VR) users, especially when using simulation software, allowing seamless switching between audio devices without navigating through operating system settings.
